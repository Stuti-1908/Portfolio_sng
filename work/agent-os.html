The brief

A film director wanted the leverage of AI agents across their creative and operational work, but unreleased scripts, contracts and schedules could not be sent to public AI services.

The brief: a private AI system that behaves like a coordinated team, runs entirely on local hardware, and that the director can run and extend without me.

CHALLENGE 01

Confidential creative material meant no cloud LLMs at all.

CHALLENGE 02

Many specialised tasks needed a reliable way to route each request to the right agent.

CHALLENGE 03

The client is not technical, so success meant full independence after handover.

The product

Master intent router

One orchestrator understands each request and routes it to the right specialist agent.

10 specialist agents

Each agent owns a domain of the director's work, with its own tools and memory.

Per-agent access control

Every agent sees only the data it needs, nothing more.

Local-first inference

Open models on Ollama. Nothing leaves the machine.

Containerised

The whole system runs in Docker for one-command start and recovery.

Hands-on training so the client runs and extends it on their own.

Engineering decisions

Hard problems, solved

01

Router before agents

A single intent router makes behaviour predictable: every request has one owner, which stops agents looping and makes failures easy to trace.

02

Least-privilege agents

Each agent has its own access scope, so a research agent can never read contracts, for example. Governance is built into the design.

03

Designed for handover

Every workflow is visual in n8n, and I trained the director on it, so the system doesn't depend on me.
