The brief

Every UI change at Infosoft broke end-to-end tests, and QA spent days per release chasing selectors instead of finding real bugs. I created Selvenza to detect and heal selector drift automatically.

CHALLENGE 01

UI refactors silently broke test selectors in React and Vite apps.

CHALLENGE 02

Repairs had to be accurate enough to trust in CI.

CHALLENGE 03

Test environments were inconsistent between machines.

Engineering decisions

Hard problems, solved

01

Semantic matching

Replacement selectors are matched by role, text and position, not brittle IDs, so healed tests keep working.

02

Built into CI

Running on every PR means drift is fixed while the change is still fresh.

03

Reproducible runs

Docker gives every run an identical environment and removes "works on my machine" failures.
