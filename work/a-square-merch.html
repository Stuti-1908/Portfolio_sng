The brief

A factory website has a different job from a storefront: it has to turn cold traffic into a qualified request for quote. A Square Merch is a fictional India-based manufacturer serving streetwear brands, corporate buyers and export clients, and I built the whole site as a self-initiated project.

The brief I set was explicit: do not think like a normal designer. That ruled out component-library defaults, so the carousel, the techniques accordion and the lookbook-style product grid are all built from scratch.

CHALLENGE 01

Eighteen categories, eleven fabrics, thirteen techniques and thirteen industries all had to be editable from an admin panel and served from a real database.

CHALLENGE 02

A pinned, scroll-driven cinematic intro had to cooperate with a smooth-scroll library that owns the scroll position.

CHALLENGE 03

Static generation of about 56 routes exhausted a free-tier Postgres connection pooler during builds.

Engineering decisions

Hard problems, solved

01

JSON-text list fields

Lists are stored as JSON text rather than native arrays, so moving from SQLite in development to Postgres in production was a one-line provider change instead of a migration.

02

Lenis owns the scroll

The intro hand-off goes through lenis.scrollTo() rather than the native API, so the library and the visible scroll position never disagree.

03

Server-side validation

Rate limiting, honeypot filtering and Zod run on the server, because client-side validation is UX and not security.
