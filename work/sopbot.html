The brief

Most companies run on tribal knowledge: processes that live in people's heads and leave when they do. Writing SOPs is slow, so nobody writes them, and automation projects stall because nobody can see which processes are worth automating.

DadaAI wanted a product that would turn that knowledge into a real process library with almost no effort from the team, and then turn the library into a data-backed automation roadmap.

CHALLENGE 01

Spoken explanations are messy: people jump between steps, skip context and mention tools in passing.

CHALLENGE 02

Every SOP had to follow the same rigorous structure (purpose, trigger, tools, steps, edge cases, completion criteria) to be usable.

CHALLENGE 03

Automation recommendations had to be ranked and defensible, not a generic list of AI ideas.

The product

Phone-in capture

Teams call a dedicated number and simply talk. No forms and no writing.

LLM structuring

A transcription and LLM pipeline extracts triggers, tools, steps, edge cases and completion criteria.

Docs that just appear

Finished SOPs are written straight into Google Docs and collected in a central dashboard.

WorkflowIQ scoring

Each process is scored for inefficiency and ranked by impact and time saved.

Executive outputs

Optimisation tables, flowcharts and executive summaries leadership can act on.

Tool recommendations

Each opportunity is mapped to a specific automation tool.

Engineering decisions

Hard problems, solved

01

Schema-first extraction

Rather than asking the model for "an SOP", every call is forced into a fixed schema, so thousands of SOPs share one reliable structure that is searchable and comparable.

02

Voice as the interface

The biggest barrier to documentation is effort. Letting people talk removes it and captures detail that a written form never would.

03

Scoring before automating

WorkflowIQ ranks processes by impact and time saved before any build starts, so clients spend automation budget where it returns most.
